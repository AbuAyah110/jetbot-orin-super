# Getting Started — JetBot Orin Super

Build order for a new **Jetson Orin Nano Super** JetBot:

1. **[Jetson setup](jetson_setup.md)** — flash to SSD, enable MAXN SUPER  
2. **[Bill of Materials](bill_of_materials_orin.md)** — order parts (power TBD for Super)  
3. **[3D printing](3d_printing.md)** — print chassis / mount / caster  
4. **[Hardware setup](hardware_setup.md)** — assemble the robot  
5. **[Software setup](software_setup/orin_native.md)** — install this package, verify I2C  
6. **[Basic motion](examples/basic_motion.md)** — first motor test  

Then explore teleoperation and the classic AI notebooks. Conversational AI (VLM / ASR / TTS / RAG) is outlined in the [roadmap](roadmap.md).
