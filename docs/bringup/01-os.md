# Stage A — OS / environment

## Install

```bash
cd /home/impulse110/Documents/jetbot-orin-super
sudo ./setup_env.sh
# or equivalently:
# sudo ./scripts/configure_jetson.sh
# sudo ./scripts/setup_swap.sh   # 32 GB default
```

Confirm:

- JetPack / L4T present (`/etc/nv_tegra_release`)
- NVMe as `/` (`df -h /`, `lsblk`)
- MAXN SUPER (`sudo nvpmodel -q`)
- Headless: `systemctl get-default` → `multi-user.target`
- 32 GB `/swapfile`, `vm.swappiness=10`

## Verify

```bash
./scripts/diagnostics.sh
```

Pass: script completes; a ~32 GB swap file is active; disk root is the NVMe; nvpmodel reports Super/MAXN if flashed for Super.
